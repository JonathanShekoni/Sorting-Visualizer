# Sorting Visualizer

A Java-based GUI application that visualizes how different sorting algorithms work step by step.
Built as a course project for CSCI 2720 - Data Structures at the University of Georgia.

## About

This application allows users to select a sorting algorithm, load data, and watch the sorting
process animate in real time. Each step of the algorithm is captured as a snapshot and rendered
visually as a bar chart, with the active element highlighted at each stage.

## Algorithms Implemented

- Bubble Sort
- Insertion Sort
- Merge Sort
- Selection Sort
- Quick Sort (multiple pivot strategies)
- Counting Sort
- Bucket Sort

## Features

- Step forward and backward through each stage of the sort
- Continuous animation mode
- Multiple algorithm selection via dropdown
- Bar value labels for small datasets
- Color gradient visualization
